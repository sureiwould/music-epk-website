# Homework 5 - SEO Changes

For this assignment, I went through all six pages of my music website and updated the SEO information. I made sure each page had its own title and description based on what that page is about.

## Home Page (index.html)
- **Title:** Kevin Sclar | Live Music, Guitar & Session Work in Jax
- **Description:** Explore live performances, original recordings, session guitar, and music production from Kevin Sclar, a Jacksonville-based musician available for bookings.
- Added Open Graph tags so my website can display a title, description, and image when shared on social media.
- Checked the headings and image alt text.

## About Page (about.html)
- **Title:** About Kevin Sclar | Jacksonville Guitarist & Musician
- **Description:** Learn about Kevin Sclar's musical background, live performance experience, and work as a guitarist, keyboardist, and recording musician in Jacksonville.
- Checked the heading structure and the alt text for my picture.

## Performances Page (performances.html)
- **Title:** Live Performances & Videos | Kevin Sclar Music in Jax
- **Description:** Watch live performance videos featuring Kevin Sclar on guitar, including shows, band performances, and highlights from Jacksonville music venues and events.
- Checked that the page has one H1 heading and that the videos have descriptive titles.

## Gallery Page (gallery.html)
- **Title:** Live Music Photo Gallery | Kevin Sclar in Jacksonville
- **Description:** Browse photos of Kevin Sclar performing live at Jacksonville venues, local music events, outdoor shows, and Battle of the Bands performances.
- Updated some of the alt text on my pictures to better describe what is happening in them.
- Checked the headings.

## Services Page (services.html)
- **Title:** Live Music & Session Recording Services | Kevin Sclar
- **Description:** Book Kevin Sclar for live guitar performances, remote or in-person session work, keyboard recording, mixing, mastering, and instrumental production services.
- Checked the headings to make sure they were organized correctly.

## Contact Page (contact.html)
- **Title:** Contact & Book Kevin Sclar | Live Music and Session Work
- **Description:** Contact Jacksonville musician Kevin Sclar to discuss live performance bookings, session guitar or keyboard work, recording projects, and music production.
- Checked that the page has one H1 heading.

## Other Changes
- Created a sitemap.xml file that lists all six pages of my website.
- Created a robots.txt file that allows search engines to crawl my website and points them to the sitemap.

## Summary
Most of my changes were in the HTML head sections. I learned that the title and meta description help search engines understand what each page is about. I also learned how Open Graph tags work when someone shares a website link. I didn't really have to change the layout of my website.
